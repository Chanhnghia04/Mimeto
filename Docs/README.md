# Tài liệu cơ chế Mimeto

Bộ tài liệu này mô tả cơ chế hiện tại của game.

## Đọc theo thứ tự

1. [Hướng dẫn hoàn thành game](03_GameCompletion_Guide.md)

## Phạm vi hiện tại

Luồng game chính là:

`StartGame → Waiting → Map → hoàn thành mục tiêu thoát → cửa thoát → Waiting`

Các scene chính đã có trong `ProjectSettings/EditorBuildSettings.asset`.
